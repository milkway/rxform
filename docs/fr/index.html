Un tableur entre.
Un XForm sort.

rxform convertit les classeurs XLSForm en XML ODK XForm — le format que parlent ODK Collect, Enketo et KoboToolbox. Une implémentation de pyxform en Rust : un binaire statique rapide, une sortie vérifiée formulaire par formulaire contre l’original, et des messages d’erreur qui pointent la cellule exacte.

B7 · quand le formulaire casse

Des erreurs qui nomment
la cellule, pas la stack.

Une coquille à la ligne 3 ne devrait pas ressembler à un rapport de crash. Chaque erreur de rxform porte la feuille, la ligne et la colonne concernées — plus une cause probable : le type de question le plus proche, la liste de choix sans doute visée, la ligne du begin qu’un end group égaré a oubliée.

  • ✓ types et ${références} mal écrits → « vouliez-vous dire … ? »
  • ✓ les groupes non fermés pointent leur ligne begin
  • ✓ les noms ambigus détectés au point d’usage
  • ✓ entities, triggers et listes vérifiés en croisé

D4 · sous le capot

Un pipeline qu’on peut montrer du doigt.

Classeur → cellules normalisées → arbre de questions → validation localisée → XML XForm, imprimé selon les conventions de pyxform pour que l’outillage existant retrouve ses repères.
